# 工时统计工具使用告知（模板 —— 上线前请交由法务/HR 审核并替换为正式文本）

本机已安装工时统计工具，用于帮助你和团队了解工作时间的分配情况。请在继续前了解以下内容：

**采集什么**：当前前台应用/窗口所属的分类（工作 / 休息 / 个人事务 / 其他）及对应时长的
每日汇总统计。**不采集**具体网址、聊天内容、按键记录、屏幕截图。

**谁能看到**：你本人可以随时通过系统托盘菜单"查看我的记录"查看全部数据。汇总统计会定期
发送至 <公司内部系统名称，由 HR/IT 填写>，可见范围为 <填写：如你的直属主管 / HR 部门>。

**用途**：仅用于工时分配统计与团队效率分析，不用于单独评估或处罚个别员工的摸鱼行为。

**退出工具**：你可以随时通过托盘菜单退出本工具，退出行为会被如实记录（而不会被阻止）。

**数据留存**：汇总统计保留 <填写：如 90 天> 后自动删除。

**联系方式**：对本工具有任何疑问，可联系 <填写：IT/HR 联系方式>。
